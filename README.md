# MAOR Property Intelligence POC

Proof of Concept לניתוח דירות בבקעת אונו. המערכת מושכת מודעות מכירה והשכרה מיד2, מדלן והומלס באמצעות Apify ומ־Komo באמצעות איסוף HTML ישיר, מנרמלת אותן למסד SQLite, שומרת היסטוריית מחיר ומחזירה ניתוח עסקה דרך API.

## אתר פעיל

גרסת Web פעילה זמינה בכתובת:

https://maor-property-intelligence.maor-vasserman.chatgpt.site

הגישה כרגע פרטית לבעלים. גרסה זו כוללת Dashboard, מודעות ממספר לוחות, 42 עסקאות ממשלתיות שיובאו ב־2 בספטמבר 2026, חישוב Deal Score, תיבת Marketplace עם OCR ושמירה מתמשכת של עסקאות וצילומי מסך. לפרטי ההרצה והפערים שנותרו ראו `docs/deployment-2026-09-02-he.md`.

OnMap מופיע ברישום המקורות כיעד חיבור, אך אינו מסומן כפעיל לפני שיהיה עבורו מחבר יציב ומאומת. לפירוט ראו `docs/multi-source-he.md`.

## הפעלה ב-GitHub Codespaces

```bash
cp .env.example .env
npm run seed
npm test
npm start
```

פתחו פורט 3000 ובדקו:

```bash
curl http://localhost:3000/health
curl http://localhost:3000/api/v1/listings
curl http://localhost:3000/api/v1/listings/1/analysis
```

כאשר הפרויקט נמצא ב-GitHub, בחרו `Code` ואז `Codespaces` ואז `Create codespace`. סביבת הפיתוח מתקינה Node.js 24, טוענת נתוני דוגמה, מריצה בדיקות ופותחת אוטומטית את פורט 3000.

לאחר הפעלת השרת, פתחו בדפדפן את כתובת פורט 3000. עמוד הבית הוא Dashboard מלא עם כרטיסי סיכום, סינון, טבלת הזדמנויות וחלונית ניתוח לכל נכס.

ה-Dashboard כולל מפת Leaflet אינטראקטיבית. סמנים נצבעים לפי Deal Score, לחיצה על סמן פותחת את ניתוח הנכס ולחיצה על שורת נכס ממקדת את המפה. נקודה ברמת רחוב מוצגת עם הילה מקווקוות ואינה מוצגת כמיקום מדויק. אריחי OpenStreetMap מתאימים ל-POC; לפני שימוש מסחרי נרחב יש לבחור ספק אריחים שמתאים לנפח השימוש ולמדיניות השירות.

להוראות מלאות ראו `docs/codespaces-he.md`.

דוח הסריקה החיה הראשונה של Komo נמצא ב־`docs/live-scan-2026-09-01-he.md`.

כאשר כמה נכסים קרובים זה לזה, המפה מאגדת אותם לאשכול המציג את מספר הנכסים ואת הציון הממוצע. לחיצה על האשכול מתקרבת לאזור, ובזום המרבי הסמנים נפרסים. מתחת למפה מוצגים גרף היסטוריית מחיר, השוואת מודעות שכירות וגרף תשואה ברוטו מול נטו. הגרפים הם SVG מקומי ואינם תלויים בספריית גרפים חיצונית.

## חיבור Apify למספר לוחות

1. צרו חשבון Apify והעתיקו Token מתוך API & Integrations.
2. הגדירו ב-Codespaces Secret בשם `APIFY_TOKEN`. אין להכניס Token לקוד או ל-Git.
3. ברירת המחדל היא `ENABLED_SOURCES=yad2,madlan,homeless,komo,ad`. הפעילו את השרת ושלחו, לדוגמה:

```bash
curl -X POST http://localhost:3000/api/v1/ingest/apify \
  -H 'content-type: application/json' \
  -d '{"source":"madlan","type":"sale","maxItems":50,"monitorMode":false}'
```

לסריקה מלאה מהממשק המקומי:

```bash
node src/scan.js
```

`ad.co.il` נסרק ישירות בעמודי המכירה וההשכרה של ארבע ערי הפיילוט. הוא מסומן כמקור מאגד, ולכן התאמה מאומתת למקור אחר מאוחדת בדשבורד ואינה נספרת כנכס נוסף.

מודעות Facebook Marketplace נקלטות דרך ה־Marketplace Inbox בדשבורד. אפשר לצרף צילום מסך עד 2MB ולהפעיל OCR מקומי בדפדפן בעברית ובאנגלית. השדות שזוהו מוצגים כהצעה בלבד וחייבים אימות לפני שמירת המודעה. אין סריקה אוטומטית של Marketplace.

פאנל `Evidence Intake` מאפשר לייבא עסקאות בפורמט JSON ממקור ממשלתי ולשמור אימותי GovMap עבור הנכס הנבחר. הערכת השווי עוברת אוטומטית לחציון וטווח בין־רבעוני של מחיר למ״ר כאשר קיימות עסקאות מתאימות. בהיעדר עסקאות, הממשק מציג במפורש שהערך מבוסס על הנחות POC.

תבניות המבנה נמצאות ב־`examples/`. הערכים בקבצי הדוגמה הם להמחשת הסכמה בלבד ואינם עסקאות או גוש/חלקה מאומתים.

## התראות וסריקה מתוזמנת

המערכת יוצרת התראה כאשר נמצאה מודעה חדשה, כאשר המחיר ירד לפחות ב-3%, או כאשר Deal Score הגיע ל-85. ניתן לשנות את הספים בקובץ `.env`.

ההתראות נשמרות במסד ומופיעות ב-Dashboard. אם מוגדר `ALERT_WEBHOOK_URL`, הן נשלחות גם כ-JSON לכתובת ה-Webhook ומסומנות כנקראו רק לאחר תשובת HTTP מוצלחת.

הקובץ `.github/workflows/property-scan.yml` מפעיל סריקה בכל שעה ושומר את מסד SQLite בין הרצות באמצעות GitHub Actions Cache. יש להגדיר ב-GitHub Secrets את `APIFY_TOKEN` ואת `ALERT_WEBHOOK_URL`. ברירת המחדל מוגבלת ל-50 תוצאות לכל מקור ולכל סוג עסקה בכל ריצה כדי לשלוט בעלויות. Cache אינו תחליף למסד מנוהל לטווח ארוך; בפריסה מסחרית יש לעבור למסד מתמשך.

בהרצה תקופתית החליפו ל-`monitorMode:true`, כדי לקבל רק מודעות חדשות או מודעות שמחירן השתנה.

## API

| Method | Route | Purpose |
|---|---|---|
| GET | `/health` | בדיקת תקינות |
| GET | `/api/v1/listings?type=sale` | רשימת מודעות |
| GET | `/api/v1/dashboard` | סיכום ונתוני Dashboard |
| GET | `/api/v1/marketplace-inbox` | מודעות Marketplace שנקלטו ידנית |
| POST | `/api/v1/marketplace-inbox` | קליטת מודעה ובדיקת התאמות חוצות לוחות |
| POST | `/api/v1/marketplace-ocr/parse` | פענוח שדות מתוך טקסט OCR |
| POST | `/api/v1/transactions/import` | ייבוא עסקאות אמת בפורמט JSON |
| POST | `/api/v1/govmap/evidence` | שמירת קואורדינטות או גוש וחלקה עם מקור וביטחון |
| GET | `/api/v1/listings/:id/govmap-link` | קישור אימות לכתובת הנכס ב־GovMap |
| GET | `/api/v1/sources` | מצב מחברים וכיסוי מודעות לפי מקור |
| GET | `/api/v1/listings/:id/cross-source-candidates` | מועמדים לאותה דירה בלוחות אחרים |
| GET | `/api/v1/listings/:id/charts` | היסטוריית מחיר, השוואות שכירות ותשואה |
| GET | `/api/v1/alerts?unread=true` | התראות, עם אפשרות לסינון שלא נקראו |
| POST | `/api/v1/alerts/:id/read` | סימון התראה כנקראה |
| POST | `/api/v1/jobs/scan` | הפעלת סריקת Apify ידנית |

אם מוגדר `SCAN_API_KEY`, קריאה אל `/api/v1/jobs/scan` חייבת לכלול Header בשם `x-scan-api-key`. אין לחשוף Endpoint שמפעיל Apify ללא הגנה בסביבה ציבורית.
| GET | `/api/v1/listings/:id/analysis` | ניתוח עם הנחות ברירת מחדל |
| POST | `/api/v1/listings/:id/analysis` | ניתוח עם הנחות מותאמות ושמירתו |
| POST | `/api/v1/ingest/apify` | משיכת נתונים מ-Apify |

## מגבלות ה-POC

מספר הבית של מודעת המעגל ב-2.48 מיליון ₪ לא נחשף בתוצאה הציבורית שנבדקה. לכן הניתוח הנוכחי הוא ברמת הרחוב, עם `address_confidence=0.55`. אין לייחס למודעה עסקאות של בניין 16 או 56 ללא אימות נוסף.

יובאו 12 עסקאות מהאתר הממשלתי, שמתוכן 7 עברו את מסנני ההשוואה הראשוניים של נכס הדוגמה. הטווח המחושב כעת הוא 3.04 עד 3.29 מיליון ₪, אך הוא נועד לסינון הזדמנויות בלבד ואינו הערכת שמאי. בחיפוש `המעגל 16` האתר הממשלתי הציג תוצאות בטבלה שכותרתה `המעגל 14`, ולכן העסקאות נשמרו עם מספר הבית המופיע בטבלה ולא יוחסו אוטומטית לנכס הדוגמה.
